# Contributing to Agent Detention

Contributions are welcome through GitHub issues and pull requests.

## Requirements

- Keep the deterministic engine dependency-free unless a dependency is justified.
- Add or update tests for behavior changes.
- Preserve the mechanical, evidence-based design.
- Do not infer private intent from observable failures.
- Do not include credentials, private state, or personal data.
- Document changes in the changelog.

Pull requests should explain the requirement being changed, the failure mode addressed, and how the change was verified.
